# Campus WWW

## Opis projektu
Projekt strony internetowej tworzony w ramach zajęć z projektowania stron WWW.

## Struktura projektu

- `docs/` – dokumentacja projektu.
- `img/` – obrazy i grafiki wykorzystywane na stronie.
- `css/` – arkusze stylów CSS.
- `js/` – skrypty JavaScript.

## Technologie
- HTML
- CSS
- JavaScript
